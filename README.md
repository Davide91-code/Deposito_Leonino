# Progetti del Corso Java & Spring Boot

Questo repository raccoglie esercitazioni pratiche e progetti sviluppati durante il percorso formativo in ambito Java e sviluppo software.

I progetti hanno l'obiettivo di consolidare progressivamente le competenze di programmazione, progettazione backend e sviluppo di applicazioni web, attraverso l'utilizzo di tecnologie e strumenti impiegati nello sviluppo software.

## Tecnologie utilizzate

- Java
- Spring Boot
- Spring Data JPA
- REST API
- MySQL
- Maven
- Git e GitHub
- Postman

## Contenuti

Il repository include esercizi e progetti relativi a:

- Programmazione Java e principi della OOP
- Gestione di classi, interfacce e collezioni
- Sviluppo di applicazioni backend
- Progettazione ed esposizione di API REST
- Persistenza dei dati tramite JPA e database relazionali
- Gestione delle richieste HTTP e delle eccezioni
- Integrazione tra servizi e componenti applicativi

I progetti vengono aggiornati progressivamente durante il percorso formativo.
